Firebase Setup Instructions

Follow these steps to set up your Firebase Realtime Database:

  1. Go to Firebase Console
  2. Create a new project or select existing one
  3. Enable Realtime Database (Start in test mode)
  4. Copy your Web API Key from Project Settings
  5. Copy your Database URL from Realtime Database section
  6. Enter credentials below to connect

Database Rules for Testing:
